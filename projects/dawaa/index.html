PROJECT 02 · HEALTHCARE

Pharmacy support, through conversation.

Dawaa is a bilingual WhatsApp pharmacy assistant concept that connects customer conversations with pharmacy information and operational workflows.

Launch application ↗View source on GitHub ↗

Overview

Dawaa explores a conversational interface for pharmacy support. The public repository presents an automation focused implementation using n8n and connected services, with a bilingual customer facing experience.

The problem

Customers may need quick answers about medicine availability and pharmacy services, while pharmacy teams need a consistent way to receive and process requests. A chat based assistant can make these interactions easier to access.

Project direction

  • Provide a conversational entry point for pharmacy-related questions.
  • Support Arabic and English interactions.
  • Connect chat messages with structured pharmacy data and workflow automation.
  • Use messaging and notification integrations to support operational follow-up.

Implementation

The public repository contains an HTML experience, workflow exports and sample data. Its current repository documentation and workflow files should be treated as the source of truth for the exact integrations and features enabled in a deployed instance.

Next development opportunities

Potential future improvements include clearer pharmacy inventory synchronization, request tracking, conversation handoff to a human pharmacist and stronger reporting for pharmacy operators.

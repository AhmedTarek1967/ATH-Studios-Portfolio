Questions

Before you open a project

Can I open the projects live?

Yes. Each project card has a Launch application button that opens the deployed page. Features that rely on n8n depend on the configured host being online.

Is the source code public?

Yes. Every project links to its public GitHub repository, including exported workflows and documentation.

Are any credentials exposed in the browser?

No. Credentials stay inside n8n, and the static pages never hold API keys or secrets.

Is Dawaa running in a real pharmacy?

No. Dawaa is a concept project that explores a bilingual chat assistant for pharmacy support.
